# Partie 4 : Cloud privé, Infrastructure as Code et cloud public

**Durée :** 21 h (chapitres 17 à 22) · **Acquis visés :** AA4, AA6, AA8, AA9

Cette partie passe de la virtualisation au cloud : modèles et architectures, cloud privé avec OpenStack, automatisation avec OpenTofu et Ansible, panorama du cloud public avec offres gratuites et simulation locale, puis exploitation et continuité de service.
